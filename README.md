# Databricks Generative AI Engineer Study Guide

Notes and architecture diagrams covering the Databricks Generative AI Engineer Associate certification curriculum.

I put these notes together while studying for the certification. The material follows the official blueprint from module 0 to module 6, focusing on how the pieces connect in Databricks: Delta tables feeding Vector Search, Unity Catalog securing agent tools, and MLflow tracking traces and evals.

## Topics Covered

- Module 0: Exam blueprint, token economics, and choosing between RAG vs fine-tuning.
- Module 1: Foundation Model APIs, structured JSON outputs, chaining, and prompt defense.
- Module 2: Medallion RAG pipelines, chunking trade-offs, and streaming Delta tables into Vector Search via Change Data Feed.
- Module 3: Mosaic AI Agents, ReAct loops, tool governance with Unity Catalog, and MLflow traces.
- Module 4: Multi-agent routing, state coordination, and Delta Lake checkpoints.
- Module 5: Evaluating RAG systems (Context Relevance, Groundedness, Answer Relevance) with MLflow.
- Module 6: Guardrails, API gateway rate limits, and egress data filters.
- Appendix: Exam cheat sheet, terms glossary, and practice questions with answers.
